# Chii Parlor

A cozy, browser-local Chiikawa fan game with a real Three.js 3D charm cabinet, squishy plushies, 12 collectible variations, four outfits, daily hearts, synthesized ambient music, and JSON collection backups.

## Play / develop

Serve `dist/` with any static server. No build step or backend is required. Progress is saved in localStorage for the current browser and origin. Export a keepsake before clearing browser data or moving to a different URL; import it on the new device. Private browsing may erase progress when closed.

Drag the cabinet to rotate, tap a plushie or use the squish button to earn five hearts, and spend 60 hearts on a guaranteed new collectible. All clothing is free. Sound starts only when enabled. Daily gifts use the device's local date. No accounts, analytics, payments, or network game saves.

## Deploy on GitHub Pages

The included workflow publishes `dist/` when pushed to `main`. In repository Settings → Pages, select GitHub Actions as the source. The workflow can also be run manually.

## Assets

Plush geometry, canvas face drawings, UI, synthesized music, and sound effects are generated by this app. This is an unofficial fan project inspired by Chiikawa; character rights belong to their respective owners. No affiliation is implied. Three.js 0.170.0 is vendored under its MIT license. Google Fonts are optional; local fallback fonts work offline. The game itself makes no external API requests.
